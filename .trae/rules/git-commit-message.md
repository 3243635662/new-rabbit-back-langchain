# Git 提交信息规范

- 使用简短清晰的中文
- 第一行不超过 50 个字符
- 采用：`类型: 描述` 格式
- 描述直接说明“做了什么”
- 避免空话和无意义描述

## 类型示例

- feat: 新功能
- fix: 修复问题
- refactor: 重构代码
- style: 样式调整
- docs: 文档修改
- chore: 配置/依赖更新
- perf: 性能优化
- test: 测试相关

## 示例
